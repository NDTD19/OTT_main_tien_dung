# OTT Arena Browser UI

This folder contains the frontend for the integrated OTT local prototype. Open the website at **http://127.0.0.1:3000** after running `npm start` in the parent directory. Opening `preview.html` directly shows only a disconnected preview and cannot upload or execute bots.

My Submissions uploads source to the Node API. Judge Console contains Submitted Bot vs Submitted Bot, which runs the chosen source programs in Docker and opens Match Arena with an actual stored replay. The built-in demo match mode remains available even without Docker.
